# PowerShell Scripts for Azure Virtual Desktop (AVD)
This folder contains a collection of PowerShell scripts designed to support Azure Virtual Desktop (AVD) environments.

The goal is to provide reusable, reliable, and production-ready scripts for image creation, host maintenance, FSLogix management, optimizations, and general AVD administration.

- Golden Image preparation
- Deployment automation
- General AVD administration tasks
- User experience optimization
- Session host maintenance

## How to Use These Scripts

You can run these scripts using any of the following methods:

- As part of an image pipeline
- Through Nerdio Scripted Actions
- Manually on master images or session hosts
- More

## Compatibility

- Scripts are designed and tested for Azure Virtual Desktop on Windows 10/11 Enterprise Multi-session
- Scripts also support AVD Personal Desktops.
- Some scripts may function on Windows Server 2019/2022, depending on the feature.
- Always validate in a test host pool before deploying widely.
